# PRIRO

**자연을 기록, 작품을 연결**

자연을 소재로 한 크리에이티브 작품을 공유하고 탐색하는 플랫폼입니다.
테라리움, 비바리움, 팔루다리움, 아쿠아스케이프 등 자연이 담긴 작품을
중심으로, 작가와 관람자를 자연스럽게 연결합니다.

---

## 어떤 플랫폼인가요?

Priro(프리로)는 '자연'을 뜻하는 이름처럼, **작품 자체가 중심**이 되는 구조를 지향합니다.

- 작가는 자신의 작품을 등록하고 세상에 선보입니다
- 관람자는 감성과 분위기 기반으로 작품을 탐색합니다
- 작품을 통해 작가와 관람자가 자연스럽게 연결됩니다
